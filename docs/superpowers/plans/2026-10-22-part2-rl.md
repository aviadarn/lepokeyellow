# Part 2 with a learned policy: RL implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train a policy that reaches Viridian Forest (map 51) from the Route 1 state under the play-time contract — pixels, the frozen world-model encoder and the objective id only, one continuous run, no rollback.

**Architecture:** A frozen JEPA encoder turns each frame into 192 floats; a ~600k-parameter GRU actor-critic reads the last four embeddings plus the objective one-hot and the previous action, and emits one of the seven existing buttons. It is trained with hand-rolled PPO against a training-only RAM reward (+1 per objective, +0.01 per new tile within the objective, plus a scaled world-model exploration bonus), with episodes started from a Go-Explore archive of save states. Evaluation runs the same net through `scripts/play2.py`'s contract-guarded loop.

**Tech Stack:** Python 3.13, torch 2.14.1 (MPS), PyBoy 2.8.1, h5py, numpy, PIL. No new dependencies — PPO is written here, as the design asks.

**Spec:** `docs/superpowers/specs/2026-10-21-part2-world-model-rl-design.md`

**Stage:** 2 of 2. Stage 1 (`docs/superpowers/plans/2026-10-21-part2-harness.md`, branch `part2-harness`) built the contract fence, the objective reads, the handlers, the control detector, the oracle, the ceiling (487 actions) and the floor (no baseline reaches any objective in 1,461).

## Scope ruling

The design names three trained arms and two stages. **This plan covers one arm, Stage A only:**

- **Arm 3** of the design: frozen world-model features + world-model exploration bonus.
- **Stage A** only: from `states/oracle/route1.state`, objectives `get_parcel` → `deliver_parcel` → `enter_forest`.

Not in this plan, and not started by it: arm 1 (pixels-only PPO + RND), arm 2 (world-model features + RND), Stage B (from a new game), imagination training. The user chose this scope explicitly. The consequence, which must be stated in the final report and in the README: **this plan can establish "a learned policy finished Part 2", and cannot establish "the world model helped."** That claim needs arms 1 and 2 and is a follow-on plan.

## Global Constraints

Copied from the spec; every task's requirements include these.

- **The play-time contract.** At play time the policy reads pixels, the frozen encoder's embeddings and the objective id. No coordinate, map-id or wall reads. No demo waypoints. No BFS distances. No emulator save/restore. Reward is training only and never a policy input. `poke.contract.PlayTimeEnv` is what enforces it; evaluation goes through it.
- **At training time anything goes:** RAM rewards, save-state resets, archives of states. Training code may read whatever it likes, and says so in its module docstring.
- Every action is logged with the controller that chose it. Turns nobody had (the input the fade-in eats) are labelled `no_control` and count as neither learned nor handler actions.
- **Action budget for evaluation: 1,461** — 3× the oracle's 487, fixed in `results/part2_ceiling.json`.
- **Done:** map 51 reached on at least 5 of 10 sampling seeds, from `states/oracle/route1.state`, within 1,461 actions, under the contract.
- **Kill and report rule:** if no training run completes `get_parcel` within the training budget fixed below, stop and revisit the reward/archive design before scaling. Report it either way.
- Python ≥ 3.12, torch, PyBoy, h5py. **CI has no ROM**: every ROM-touching script must pass `--help` in CI, and logic gets unit tests with fakes. **276 tests today, and they must stay green.**
- The ROM, `states/`, `episodes/` and `checkpoints/` stay out of git. `results/*.json` and `media/*.gif` are committed.
- Local Apple M5 (MPS), $0. No cloud training.
- DMG mode stays (`cgb=False`); channel 0 is luminance.

Checkpoint every 10 updates and on the hour, so a run killed early is still readable.

## Review Focus

Five input classes the spec implies, that no task's own happy-path test exercises, most likely to bite first. Each has a test pinned to the task that owns the code.

1. **A blackout mid-episode.** Pikachu faints to a wild Pidgey; the game warps the player home (map 37/38) or to a Pokémon Center (41) and the party heals. Event flags do not change, so `current()` still reports the same objective while the player is suddenly 40 tiles away. Expected: the episode continues (the design refuses to special-case it), no objective is credited, and the tile bonus for the respawn room is paid at most once. Owned by **Task 1** (`test_blackout_credits_no_objective`) and **Task 5** (`test_blackout_does_not_end_the_episode`).
2. **A checkpoint whose encoder geometry disagrees with the policy.** `checkpoints/yellow_v2` is `dim=192, num_frames=4`; a refreshed one trained with other flags is not. Loading it into a policy built for 4×192 silently produces a wrong-shaped observation or, worse, a right-shaped one from the wrong frames. Expected: a named error at load, not a shape error 200 lines later. Owned by **Task 3** (`test_checkpoint_geometry_mismatch_raises`).
3. **An archive state captured with a text box open.** Snapshots are taken during training, including on turns the handler owned. Restoring one means the policy's first observation is a dialogue it cannot act on, and the handler owns the whole episode. Expected: the archive refuses to store a state without control, and `reset()` runs handler expansion before returning the first observation. Owned by **Task 2** (`test_archive_refuses_a_state_without_control`) and **Task 5** (`test_reset_expands_handlers_before_first_obs`).
4. **Objective regression.** `current()` reads flags and the bag; the bag empties when Oak takes the parcel, and a mid-scene state can read an earlier objective than one already completed. Expected: an objective is paid for exactly once per episode, whatever order the readings arrive in, and the tile set resets on change rather than on "advance". Owned by **Task 1** (`test_an_objective_is_credited_once_even_if_the_reading_regresses`).
5. **A worker that dies mid-rollout.** PyBoy raises, or the process is killed; the driver is mid-`recv` on a pipe. Expected: the driver notices, drops that worker's partial rollout rather than training on zeros, restarts it from the archive, and records the restart in the run log. Owned by **Task 9** (`test_a_dead_worker_is_restarted_and_its_partial_rollout_dropped`).

"""The training reward. It reads RAM on purpose: it is never a policy input."""

import pytest

from poke.flags import GOT_OAKS_PARCEL, OAK_GOT_PARCEL, GOT_POKEDEX
from poke.games import YELLOW
from poke.rl.reward import OBJECTIVE_REWARD, TILE_REWARD, RewardState, step_reward


class FakeEnv:
    """Enough env for flags, the bag and position."""

    def __init__(self, ram=None, bits=(), tile=(12, 35, 10)):
        self.game = YELLOW
        self.ram_values = dict(ram or {})
        self.tile = tile
        for bit in bits:
            self.set_bit(bit, 1)

    def set_bit(self, index, value):
        addr = YELLOW.ram.event_flags + index // 8
        byte = self.ram_values.get(addr, 0)
        mask = 1 << (index % 8)
        self.ram_values[addr] = (byte | mask) if value else (byte & ~mask)

    def read_ram(self, addr):
        if addr == YELLOW.ram.cur_map:
            return self.tile[0]
        if addr == YELLOW.ram.y_coord:
            return self.tile[1]
        if addr == YELLOW.ram.x_coord:
            return self.tile[2]
        if addr == YELLOW.ram.num_bag_items:
            return 0
        return self.ram_values.get(addr, 0)


def route1_env(**kwargs):
    """Stage A's start: the rival fight is done, nothing else is."""
    from poke.flags import BATTLED_RIVAL_IN_OAKS_LAB, OAK_APPEARED_IN_PALLET
    return FakeEnv(bits=(OAK_APPEARED_IN_PALLET, BATTLED_RIVAL_IN_OAKS_LAB), **kwargs)


def test_a_new_tile_pays_once():
    env = route1_env()
    state = RewardState.start(env)
    assert step_reward(env, state) == (TILE_REWARD, [])
    assert step_reward(env, state) == (0.0, [])


def test_completing_an_objective_pays_one():
    env = route1_env()
    state = RewardState.start(env)
    step_reward(env, state)
    env.set_bit(GOT_OAKS_PARCEL, 1)
    env.tile = (42, 5, 2)
    reward, completed = step_reward(env, state)
    assert completed == ["get_parcel"]
    assert reward == pytest.approx(OBJECTIVE_REWARD + TILE_REWARD)


def test_the_tile_set_resets_when_the_objective_changes():
    env = route1_env()
    state = RewardState.start(env)
    step_reward(env, state)
    env.set_bit(GOT_OAKS_PARCEL, 1)
    step_reward(env, state)
    env.tile = (12, 35, 10)          # the very first tile again
    reward, _ = step_reward(env, state)
    assert reward == pytest.approx(TILE_REWARD), "the walk back is new ground"


def test_objectives_already_true_at_the_start_are_not_credited():
    env = route1_env()
    env.set_bit(GOT_OAKS_PARCEL, 1)
    state = RewardState.start(env)
    reward, completed = step_reward(env, state)
    assert completed == []
    assert reward == pytest.approx(TILE_REWARD)


def test_an_objective_is_credited_once_even_if_the_reading_regresses():
    """Review focus 4: `current()` can move backwards. Pay once anyway."""
    env = route1_env()

    env.set_bit(GOT_OAKS_PARCEL, 1)

"""Reinforcement learning. Everything under this package is TRAINING TIME.

Training-time code may read RAM, restore save states and compute rewards. The
play-time surface is `poke.contract.PlayTimeEnv`, and the only module here
that a policy touches through it is `poke.rl.policy`, which sees embeddings.
"""

```python
# poke/rl/reward.py
"""The training reward. Never a policy input.

From the design: +1 per objective completed, +0.01 per new (map, y, x) tile
within the current objective, and the visited set resets when the objective
changes -- which is what makes the walk back to Oak pay a second time. No
level, heal or battle terms: prior art shows every one of those got hacked.

Two things this file is careful about, both learned from the cartridge rather
than from the design. An objective is credited at most once per episode, held
in a set rather than an index, because `poke.objectives.current` reads flags
and the bag and can report an earlier objective than one already finished --
the bag empties the moment Oak takes the parcel. And objectives already true
when the episode starts are never credited: an archive state that begins after
the Mart would otherwise pay +1 for a save state rather than for a walk.
"""

from __future__ import annotations

from dataclasses import dataclass, field

from poke.objectives import CHAIN, current

#: What one milestone is worth.
OBJECTIVE_REWARD = 1.0
#: What one previously unvisited tile is worth, inside the current objective.
TILE_REWARD = 0.01


@dataclass
class RewardState:
    """Per-episode reward memory. Reset with the episode, never shared."""

    objective_key: str
    tiles: set[tuple] = field(default_factory=set)
    credited: set[str] = field(default_factory=set)

    @classmethod
    def start(cls, env) -> "RewardState":
        return cls(
            objective_key=current(env).key,
            credited={o.key for o in CHAIN if o.reached(env)},
        )


def step_reward(env, state: RewardState) -> tuple[float, list[str]]:
    """Reward for the transition just taken, and the objectives it completed.

    Call once per emulator action, after the action, including handler actions:
    the parcel is collected by a handler's A press, and an objective that only
    a policy turn could pay for would never be paid.
    """
    reward, completed = 0.0, []
    for objective in CHAIN:
        if objective.key not in state.credited and objective.reached(env):
            state.credited.add(objective.key)
            completed.append(objective.key)
            reward += OBJECTIVE_REWARD

    key = current(env).key
    if key != state.objective_key:
        state.objective_key = key
        state.tiles = set()

    ram = env.game.ram
    tile = (env.read_ram(ram.cur_map), env.read_ram(ram.y_coord),
            env.read_ram(ram.x_coord))
    if tile not in state.tiles:
        state.tiles.add(tile)
        reward += TILE_REWARD

    return reward, completed
```

# poke/rl/archive.py
"""Go-Explore archive: where training episodes start from.

Training only -- it restores save states, which play time bans.

A cell is (objective index, map, y // CELL, x // CELL). Coarse on purpose: one
cell per tile would store a quarter of a megabyte per step and teach the policy
to start from everywhere equally, and the point of the archive is to make the
places the policy rarely reaches cheap to practise.

Sampling weight is 1 / sqrt(1 + visits), the Go-Explore rule: a cell that has
been started from four hundred times is not where the policy is weak any more.

Two refusals, both measured rather than defensive. A state captured without
control -- a text box, a battle -- starts an episode the handler owns from the
first turn, so `add` checks `has_control` and declines. And the capacity is a
byte budget in disguise: at 178,101 bytes a state, the default 2,000 cells is
about 356 MB, which the driver holds while four workers hold their own
emulators.
"""

from __future__ import annotations

import random
from dataclasses import dataclass, field

from poke.control import has_control
from poke.objectives import current

#: Tiles per archive cell, on each axis.
CELL = 4
#: Cells kept. 2,000 x 178,101 bytes is about 356 MB.
DEFAULT_CAPACITY = 2000


@dataclass
class Cell:
    key: tuple
    blob: bytes
    visits: int = 0
    found_at: int = 0


class Archive:
    def __init__(self, capacity: int = DEFAULT_CAPACITY, rng=None):
        self.capacity = capacity
        self.rng = rng or random.Random()
        self.cells: dict[tuple, Cell] = {}
        self.added = 0
        self.rejected_without_control = 0

    def key_for(self, env) -> tuple:
        ram = env.game.ram
        y = env.read_ram(ram.y_coord) or 0
        x = env.read_ram(ram.x_coord) or 0
        return (current(env).index, env.read_ram(ram.cur_map), y // CELL, x // CELL)

    def add(self, env, blob: bytes | None = None) -> bool:
        """Store this position if it is a new cell. True when it was new."""
        if not has_control(env):
            self.rejected_without_control += 1
            return False
        key = self.key_for(env)
        if key in self.cells:
            return False
        self.added += 1
        self.cells[key] = Cell(key=key, blob=blob if blob is not None else env.snapshot(),
                               found_at=self.added)
        if len(self.cells) > self.capacity:
            # The most-visited cell has the least left to teach.
            crowded = max(self.cells.values(), key=lambda cell: (cell.visits, -cell.found_at))
            del self.cells[crowded.key]
        return True

    def note_visit(self, key: tuple) -> None:
        cell = self.cells.get(key)
        if cell is not None:
            cell.visits += 1

    def sample(self) -> bytes | None:
        """A start state, weighted towards cells started from least."""
        if not self.cells:
            return None
        cells = list(self.cells.values())
        weights = [1.0 / ((1.0 + cell.visits) ** 0.5) for cell in cells]
        return self.rng.choices(cells, weights=weights, k=1)[0].blob

    def __len__(self) -> int:
        return len(self.cells)

    def stats(self) -> dict:
        return {
            "cells": len(self.cells),
            "maps": sorted({key[1] for key in self.cells}),
            "objectives": sorted({key[0] for key in self.cells}),
            "bytes": sum(len(cell.blob) for cell in self.cells.values()),
            "rejected_without_control": self.rejected_without_control,
        }

```python
# poke/rl/features.py
"""The world model, frozen, as the policy's eyes.

The encoder is the only part of the JEPA the policy uses: 144x160 greyscale in,
192 floats out. It is frozen during RL by the design -- one refresh is allowed
between data collections, never a gradient from the policy -- so this wrapper
puts the model in eval mode and clears requires_grad once, at load.

Only the newest frame is encoded each step. The policy sees four, and three of
them it saw last step already, so `EmbeddingStack` keeps them and the encoder
runs once per action instead of four times. At the measured ~1,758 frames/s
that is the difference between the encoder being the bottleneck and being four
times the bottleneck.

The geometry check is not ceremony. `scripts/train.py` takes --num-frames and
the model takes --dim, and a checkpoint trained with other values loads into
this class without complaint and produces a plausible, wrong observation. The
load raises instead, naming both numbers.
"""

from __future__ import annotations

from pathlib import Path

import numpy as np
import torch

from poke.goals import default_device
from poke.jepa import JEPA


def checkpoint_geometry(blob: dict) -> tuple[int, int | None]:
    """(embedding dim, frames per window) as the checkpoint recorded them.

    The dim is read from the weights rather than the config, because
    DefaultConfig has no dim field -- the encoder's class token carries it.
    """
    weights = blob["jepa"]
    dim = int(weights["encoder.cls"].shape[-1])
    config = blob.get("config") or {}
    frames = config.get("num_frames")
    return dim, None if frames is None else int(frames)


class FrozenEncoder:
    def __init__(self, checkpoint, device: str | None = None, expect_frames: int = 4):
        self.path = Path(checkpoint)
        blob = torch.load(self.path, map_location="cpu", weights_only=False)
        dim, frames = checkpoint_geometry(blob)
        if frames is not None and frames != expect_frames:
            raise ValueError(
                f"{self.path} was trained with num_frames={frames}; this policy "
                f"is built for num_frames={expect_frames}. Retrain the encoder "
                "or rebuild the policy -- the window has to be the same one."
            )
        self.dim = dim
        self.num_frames = expect_frames
        self.device = device or default_device()
        self.model = JEPA(num_frames=expect_frames, dim=dim)
        self.model.load_state_dict(blob["jepa"])
        self.model.eval().to(self.device)
        self.model.requires_grad_(False)

    @property
    def out_dim(self) -> int:
        """What the policy's observation gets from the pixels."""
        return self.num_frames * self.dim

    @torch.no_grad()
    def embed(self, frames: np.ndarray) -> np.ndarray:
        """[B, 144, 160] uint8 luminance -> [B, dim] float32.

        The scaling matches scripts/play.py's to_tensor and poke.dataset, so a
        frame means the same thing to this encoder as it did in training.
        """
        pixels = np.asarray(frames, dtype=np.float32) / 127.5 - 1.0
        batch = torch.from_numpy(pixels).unsqueeze(1).to(self.device)
        out = self.model.encode(batch)
        return out.detach().to("cpu").numpy().astype(np.float32)


class EmbeddingStack:
    """The last `num_frames` embeddings, oldest first.

    `reset` fills every slot with the first embedding rather than zero-padding:
    a zero window is a state the encoder never produces, and the policy would
    spend its first three actions of every episode in one.
    """

    def __init__(self, num_frames: int = 4, dim: int = 192):
        self.num_frames = num_frames
        self.dim = dim
        self.buffer: np.ndarray | None = None

    def reset(self, embedding: np.ndarray) -> None:
        self.buffer = np.tile(np.asarray(embedding, dtype=np.float32), (self.num_frames, 1))

    def push(self, embedding: np.ndarray) -> None:
        if self.buffer is None:
            raise RuntimeError("EmbeddingStack.reset must run before push")
        self.buffer = np.roll(self.buffer, -1, axis=0)
        self.buffer[-1] = np.asarray(embedding, dtype=np.float32)

    def vector(self) -> np.ndarray:
        if self.buffer is None:
            raise RuntimeError("EmbeddingStack.reset must run before vector")
        return self.buffer.reshape(-1)
```

```python
# poke/rl/policy.py
"""The policy: a small recurrent actor-critic over frozen embeddings.

Input, in the design's words: four frame embeddings, the objective one-hot and
the previous action. Body: an MLP into a GRU for memory. Output: logits over
the seven existing actions and a value.

Memory is not decoration here. The contract forbids reading position, so "I
just walked into this wall" is only available to the policy as a difference
between successive embeddings, and the GRU is where that difference can live.

The previous action is in the observation for the same reason: a frame after a
no-op and a frame after walking into a wall are the same frame.
"""

from __future__ import annotations

import numpy as np
import torch
import torch.nn as nn

from poke.actions import n_actions as action_count
from poke.objectives import N_OBJECTIVES


def observation(window, objective_one_hot, prev_action: int, n_actions: int) -> np.ndarray:
    """The policy's input vector: embeddings, objective, previous action."""
    previous = np.zeros(n_actions, dtype=np.float32)
    previous[prev_action] = 1.0
    return np.concatenate([
        np.asarray(window, dtype=np.float32),
        np.asarray(objective_one_hot, dtype=np.float32),
        previous,
    ])


class ActorCritic(nn.Module):
    def __init__(
        self,
        feature_dim: int = 192,
        num_frames: int = 4,
        n_objectives: int = N_OBJECTIVES,
        n_actions: int | None = None,
        hidden: int = 256,
    ) -> None:
        super().__init__()
        self.n_actions = n_actions or action_count()
        self.hidden_size = hidden
        self.obs_dim = feature_dim * num_frames + n_objectives + self.n_actions
        self.body = nn.Sequential(nn.Linear(self.obs_dim, hidden), nn.Tanh())
        self.gru = nn.GRUCell(hidden, hidden)
        self.actor = nn.Linear(hidden, self.n_actions)
        self.critic = nn.Linear(hidden, 1)
        # A near-uniform policy at step zero. Large initial logits make PPO's
        # first ratio enormous and the clip does the rest of the damage.
        nn.init.orthogonal_(self.actor.weight, gain=0.01)
        nn.init.zeros_(self.actor.bias)

    def initial_hidden(self, batch: int, device) -> torch.Tensor:
        return torch.zeros(batch, self.hidden_size, device=device)

    def forward(self, obs: torch.Tensor, hidden: torch.Tensor):
        hidden = self.gru(self.body(obs), hidden)
        return self.actor(hidden), self.critic(hidden).squeeze(-1), hidden

    def act(self, obs: torch.Tensor, hidden: torch.Tensor, greedy: bool = False) -> dict:
        logits, value, hidden = self(obs, hidden)
        distribution = torch.distributions.Categorical(logits=logits)
        action = logits.argmax(dim=-1) if greedy else distribution.sample()
        return {
            "action": action,
            "logprob": distribution.log_prob(action),
            "value": value,
            "entropy": distribution.entropy(),
            "hidden": hidden,
        }

    def evaluate(self, obs_seq: torch.Tensor, hidden0: torch.Tensor,
                 actions: torch.Tensor) -> dict:
        """Replay [T, B, obs] through the GRU from a stored hidden state.

        PPO needs the logprobs of actions already taken, under the current
        weights. With a recurrent policy that means replaying the sequence in
        order -- shuffling timesteps into minibatches would feed the GRU a
        hidden state from a different trajectory.
        """
        logprobs, values, entropies = [], [], []
        hidden = hidden0
        for step in range(obs_seq.size(0)):
            logits, value, hidden = self(obs_seq[step], hidden)
            distribution = torch.distributions.Categorical(logits=logits)
            logprobs.append(distribution.log_prob(actions[step]))
            values.append(value)
            entropies.append(distribution.entropy())
        return {
            "logprobs": torch.stack(logprobs),
            "values": torch.stack(values),
            "entropy": torch.stack(entropies),
            "hidden": hidden,
        }
```

```python
# poke/rl/trainenv.py
"""One emulator, the handlers and the reward, as a step/reset loop.

TRAINING ONLY: it reads position for the reward and restores save states from
the archive. The same handlers run here as at play time -- `poke.handlers` is
the single declared harness -- so a policy trained here meets no surprises in
`scripts/play2.py`.

One policy action expands into the handler turns that follow it, as the design
specifies, and every one of them counts against the episode budget. A run that
spends its budget in menus has not navigated anywhere, and a policy that is
never charged for walking into a dialogue will keep doing it.

`max_handler_steps` bounds the expansion. The handlers can legitimately own
dozens of turns in a row (Oak's lecture), but an unbounded loop here means one
policy step can swallow a whole episode, and `poke.handlers.BOX_PATIENCE`
already yields a turn back every 32.
"""

from __future__ import annotations

from dataclasses import dataclass, field

import numpy as np

from poke.handlers import HandlerState, choose
from poke.objectives import one_hot
from poke.rl.reward import RewardState, step_reward

#: Actions per training episode, handler turns included.
EPISODE_LEN = 512
#: How many handler turns one policy action may expand into.
MAX_HANDLER_STEPS = 64
#: The objective that ends an episode by succeeding.
TERMINAL_OBJECTIVE = "enter_forest"


@dataclass
class Step:
    frame: np.ndarray
    objective: list[float]
    reward: float
    done: bool
    info: dict = field(default_factory=dict)


class TrainEnv:
    def __init__(self, rom: str | None = None, state_path: str | None = None,
                 episode_len: int = EPISODE_LEN,
                 max_handler_steps: int = MAX_HANDLER_STEPS, env=None):
        if env is None:
            from poke.env import PokeEnv      # imported late: tests run without a ROM
            env = PokeEnv(rom, state_path)
        self.env = env
        self.episode_len = episode_len
        self.max_handler_steps = max_handler_steps
        self.handlers = HandlerState()
        self.rewards = RewardState(objective_key="", credited=set())
        self.taken = 0
        self.completed: list[str] = []
        self.controllers: dict[str, int] = {}

    # -- the emulator ------------------------------------------------------

    def _map(self):
        return self.env.read_ram(self.env.game.ram.cur_map)

    def _take(self, action_index: int, controller: str) -> float:
        before = self._map()
        self.env.step(action_index)
        self.taken += 1
        reward, completed = step_reward(self.env, self.rewards)
        self.handlers.note(action_index, self._map() != before)
        self.completed.extend(completed)
        self.controllers[controller] = self.controllers.get(controller, 0) + 1
        return reward

    def _drain_handlers(self) -> tuple[float, int]:
        """Take every turn the handlers claim, up to the cap."""
        reward, steps = 0.0, 0
        while steps < self.max_handler_steps and not self._over():
            claimed = choose(self.env, self.handlers)
            if claimed is None:
                break
            action, controller = claimed
            reward += self._take(action, controller)
            steps += 1
        return reward, steps

    def _over(self) -> bool:
        return self.taken >= self.episode_len or TERMINAL_OBJECTIVE in self.completed

    def _observe(self, reward: float, handler_steps: int) -> Step:
        ram = self.env.game.ram
        return Step(
            frame=self.env.screen()[:, :, 0],
            objective=one_hot(self.env),
            reward=reward,
            done=self._over(),
            info={
                "map": self._map(),
                "y": self.env.read_ram(ram.y_coord),
                "x": self.env.read_ram(ram.x_coord),
                "completed": list(self.completed),
                "controllers": dict(self.controllers),
                "handler_steps": handler_steps,
                "taken": self.taken,
            },
        )

    # -- the loop ----------------------------------------------------------

    def reset(self, blob: bytes | None = None) -> Step:
        if blob is None:
            self.env.reset()
        else:
            self.env.restore(blob)
        self.handlers = HandlerState()
        self.rewards = RewardState.start(self.env)
        self.taken = 0
        self.completed = []
        self.controllers = {}
        # Hand the policy a frame it can act on. An archive state captured
        # mid-dialogue otherwise gives it an observation whose only legal
        # answer is the handler's.
        _, handler_steps = self._drain_handlers()
        return self._observe(reward=0.0, handler_steps=handler_steps)

    def step(self, action_index: int) -> Step:
        reward = self._take(action_index, "policy")
        drained, handler_steps = self._drain_handlers()
        return self._observe(reward=reward + drained, handler_steps=handler_steps)

    def snapshot(self) -> bytes:
        return self.env.snapshot()
```

```python
# poke/rl/ppo.py
"""PPO, written here rather than pulled in.

The design prefers no heavy new dependency, and the recurrent part is the
reason it is cheap to write and expensive to borrow: with a GRU in the policy,
a minibatch is a set of whole trajectories, not a shuffled bag of timesteps.
Most implementations shuffle. One that shuffles here feeds the GRU a hidden
state recorded in a different episode, and the logprobs it computes are of a
policy that never existed.

So: the buffer is [T, N], advantages are computed backwards per env with the
done mask breaking the chain, and minibatches are splits over N.

gamma is 0.999 by default. The eval budget is 1,461 actions and the parcel
errand is a few hundred of them; at the usual 0.99 a reward 400 steps away is
worth 0.018 of itself, which is indistinguishable from the tile bonus noise.
"""

from __future__ import annotations

from dataclasses import dataclass

import torch
import torch.nn as nn


@dataclass
class PPOConfig:
    gamma: float = 0.999
    gae_lambda: float = 0.95
    clip: float = 0.2
    vf_coef: float = 0.5
    ent_coef: float = 0.01
    lr: float = 3e-4
    max_grad_norm: float = 0.5
    epochs: int = 4
    #: Envs per minibatch. Whole trajectories, never sliced in time.
    minibatch_envs: int = 2


def surrogate(ratio: torch.Tensor, advantage: torch.Tensor, clip: float) -> torch.Tensor:
    """The clipped objective, as a loss (so: negated, and summed by the caller)."""
    unclipped = ratio * advantage
    clipped = torch.clamp(ratio, 1.0 - clip, 1.0 + clip) * advantage
    return -torch.min(unclipped, clipped).mean()


class RolloutBuffer:
    def __init__(self, steps: int, envs: int, obs_dim: int, device="cpu"):
        self.steps, self.envs = steps, envs
        self.device = device
        self.obs = torch.zeros(steps, envs, obs_dim, device=device)
        self.actions = torch.zeros(steps, envs, dtype=torch.long, device=device)
        self.logprobs = torch.zeros(steps, envs, device=device)
        self.values = torch.zeros(steps, envs, device=device)
        self.rewards = torch.zeros(steps, envs, device=device)
        self.dones = torch.zeros(steps, envs, device=device)
        self.advantages = torch.zeros(steps, envs, device=device)
        self.returns = torch.zeros(steps, envs, device=device)

    def add(self, t: int, obs, action, logprob, value, reward, done) -> None:
        self.obs[t] = obs
        self.actions[t] = action
        self.logprobs[t] = logprob
        self.values[t] = value
        self.rewards[t] = reward
        self.dones[t] = done

    def compute_returns(self, last_value, last_done, config: PPOConfig) -> None:
        """Generalised advantage estimation, backwards, done-masked."""
        advantage = torch.zeros(self.envs, device=self.device)
        for t in reversed(range(self.steps)):
            if t == self.steps - 1:
                next_value, next_done = last_value, last_done
            else:
                next_value, next_done = self.values[t + 1], self.dones[t + 1]
            alive = 1.0 - self.dones[t]
            delta = self.rewards[t] + config.gamma * next_value * (1.0 - next_done) - self.values[t]
            # `alive` zeroes the whole term on a terminal step: nothing after
            # an episode ends is evidence about the action that ended it.
            advantage = alive * (delta + config.gamma * config.gae_lambda
                                 * (1.0 - next_done) * advantage)
            self.advantages[t] = advantage
        self.returns = self.advantages + self.values

    @staticmethod
    def env_batches(envs: int, size: int):
        for start in range(0, envs, size):
            yield list(range(start, min(start + size, envs)))


def ppo_update(policy, optimizer, buffer: RolloutBuffer, config: PPOConfig,
               hidden0: torch.Tensor) -> dict:
    """One PPO pass over a filled buffer. Returns the diagnostics worth logging."""
    advantages = buffer.advantages
    normalised = (advantages - advantages.mean()) / (advantages.std() + 1e-8)

    stats = {"policy_loss": 0.0, "value_loss": 0.0, "entropy": 0.0,
             "approx_kl": 0.0, "clip_fraction": 0.0}
    passes = 0
    for _ in range(config.epochs):
        for envs in RolloutBuffer.env_batches(buffer.envs, config.minibatch_envs):
            index = torch.tensor(envs, device=buffer.device)
            out = policy.evaluate(buffer.obs[:, index], hidden0[index], buffer.actions[:, index])
            ratio = (out["logprobs"] - buffer.logprobs[:, index]).exp()
            policy_loss = surrogate(ratio, normalised[:, index], config.clip)
            value_loss = nn.functional.mse_loss(out["values"], buffer.returns[:, index])
            entropy = out["entropy"].mean()
            loss = policy_loss + config.vf_coef * value_loss - config.ent_coef * entropy

            optimizer.zero_grad(set_to_none=True)
            loss.backward()
            nn.utils.clip_grad_norm_(policy.parameters(), config.max_grad_norm)
            optimizer.step()

            with torch.no_grad():
                stats["policy_loss"] += policy_loss.item()
                stats["value_loss"] += value_loss.item()
                stats["entropy"] += entropy.item()
                stats["approx_kl"] += ((ratio - 1) - ratio.log()).mean().item()
                stats["clip_fraction"] += ((ratio - 1).abs() > config.clip).float().mean().item()
            passes += 1

    return {key: value / max(passes, 1) for key, value in stats.items()}
```

# scripts/compare_bonus.py
"""Prediction error or ensemble disagreement? Measure, then pick.

The design leaves this to the builder and says to pick after a small
comparison. The comparison is: which signal is higher on transitions from maps
the encoder never trained on, and lower on maps it did? That is exactly what
an exploration bonus is for, and it is answerable offline from the episode
files already on disk -- no RL run required.

Score is AUC: the probability that a randomly chosen unseen-map transition
scores above a randomly chosen seen-map one. 0.5 is a coin flip.

Prediction error uses the frozen JEPA's own predictor. Disagreement trains a
small ensemble of MLP heads on the same frozen embeddings for one pass and
takes their variance -- cheap, and the Plan2Explore construction.
"""

from __future__ import annotations

import argparse
import json
from pathlib import Path

import h5py
import numpy as np
import torch
import torch.nn as nn

from poke.goals import default_device
from poke.rl.features import FrozenEncoder

ENSEMBLE = 4
HIDDEN = 256


def auc(unseen: np.ndarray, seen: np.ndarray) -> float:
    """Probability a random unseen score beats a random seen one. Rank-based."""
    if len(unseen) == 0 or len(seen) == 0:
        return float("nan")
    joined = np.concatenate([unseen, seen])
    order = joined.argsort().argsort().astype(np.float64) + 1.0
    rank_sum = order[: len(unseen)].sum()
    return float((rank_sum - len(unseen) * (len(unseen) + 1) / 2) / (len(unseen) * len(seen)))


def load_transitions(path, encoder, limit):
    """(embedding, action multihot, next embedding, map) for consecutive frames."""
    with h5py.File(path, "r") as handle:
        frames = handle["frames"][:limit, :, :, 0]
        actions = handle["actions"][:limit].astype(np.float32)
        location = handle["location"][:limit] if "location" in handle else None
    embeddings = []
    for start in range(0, len(frames), 256):
        embeddings.append(encoder.embed(frames[start:start + 256]))
    embeddings = np.concatenate(embeddings)
    maps = location[:, 0] if location is not None else np.full(len(frames), -1)
    return embeddings[:-1], actions[:-1], embeddings[1:], maps[:-1]


def prediction_error(jepa, device, embeddings, actions, nexts) -> np.ndarray:
    errors = []
    with torch.no_grad():
        for start in range(0, len(embeddings), 256):
            stop = start + 256
            initial = torch.from_numpy(embeddings[start:stop]).to(device)
            button = torch.from_numpy(actions[start:stop]).unsqueeze(1).to(device)
            predicted = jepa.rollout(initial, button)[:, 0]
            target = torch.from_numpy(nexts[start:stop]).to(device)
            errors.append(((predicted - target) ** 2).mean(dim=-1).cpu().numpy())
    return np.concatenate(errors)


def ensemble_disagreement(device, embeddings, actions, nexts, seed=0) -> np.ndarray:
    torch.manual_seed(seed)
    dim, n_buttons = embeddings.shape[1], actions.shape[1]
    heads = [nn.Sequential(nn.Linear(dim + n_buttons, HIDDEN), nn.ReLU(),
                           nn.Linear(HIDDEN, dim)).to(device) for _ in range(ENSEMBLE)]
    inputs = torch.from_numpy(np.concatenate([embeddings, actions], axis=1)).to(device)
    targets = torch.from_numpy(nexts).to(device)
    for index, head in enumerate(heads):
        optimizer = torch.optim.Adam(head.parameters(), lr=1e-3)
        # Each head sees a different bootstrap sample, or they agree by
        # construction and the variance measures nothing.
        generator = np.random.default_rng(seed + index)
        order = generator.integers(0, len(inputs), size=len(inputs))
        for start in range(0, len(order), 256):
            batch = torch.from_numpy(order[start:start + 256]).to(device)
            loss = nn.functional.mse_loss(head(inputs[batch]), targets[batch])
            optimizer.zero_grad(set_to_none=True)
            loss.backward()
            optimizer.step()
    with torch.no_grad():
        stacked = torch.stack([head(inputs) for head in heads])
    return stacked.var(dim=0).mean(dim=-1).cpu().numpy()


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--checkpoint", default="checkpoints/part2/best.pt")
    parser.add_argument("--episodes", default="episodes/part2.h5")
    parser.add_argument("--unseen-maps", type=int, nargs="+", default=[50, 51],
                        help="maps treated as novel; the bonus should rank these higher")
    parser.add_argument("--limit", type=int, default=20000)
    parser.add_argument("--device", default=default_device())
    parser.add_argument("--out", default="results/intrinsic_comparison.json")
    args = parser.parse_args()

    encoder = FrozenEncoder(args.checkpoint, device=args.device)
    embeddings, actions, nexts, maps = load_transitions(args.episodes, encoder, args.limit)
    unseen = np.isin(maps, args.unseen_maps)

    scores = {
        "prediction_error": prediction_error(encoder.model, args.device, embeddings, actions, nexts),
        "ensemble_disagreement": ensemble_disagreement(args.device, embeddings, actions, nexts),
    }
    report = {
        "episodes": args.episodes,
        "checkpoint": args.checkpoint,
        "unseen_maps": args.unseen_maps,
        "transitions": int(len(embeddings)),
        "unseen_transitions": int(unseen.sum()),
        "auc": {name: auc(value[unseen], value[~unseen]) for name, value in scores.items()},
    }
    report["chosen"] = max(report["auc"], key=lambda name: report["auc"][name])
    Path(args.out).parent.mkdir(parents=True, exist_ok=True)
    Path(args.out).write_text(json.dumps(report, indent=1))
    print(json.dumps(report, indent=1))

# poke/rl/intrinsic.py
"""The world-model exploration bonus. Training only.

Plan2Explore-style: the policy is paid for transitions the world model did not
see coming. Which "did not see coming" means was measured rather than chosen --
see scripts/compare_bonus.py and MEASURED below.

Two rules the design is explicit about, both kept by the caller rather than
here: the bonus is computed only on transitions the policy controlled, because
text boxes and the Pikachu-follow sprite are noisy-TV sources that a handler
turn walks straight into; and it is never a policy input, only a reward term.

Scale: raw latent MSE has no natural size, and an objective pays exactly 1.0.
So the raw value is divided by its own running standard deviation before the
coefficient applies, which keeps a surprising frame worth a few hundredths.
"""

from __future__ import annotations

import numpy as np
import torch

from poke.actions import to_multihot

#: Which signal, and how well it separated novel maps from familiar ones.
#: Filled in from results/intrinsic_comparison.json -- see the plan's Task 8.
MEASURED = {
    "report": "results/intrinsic_comparison.json",
    "chosen": "prediction_error",
    "auc": None,
    "note": "replaced by scripts/compare_bonus.py output before training starts",
}


class RunningNorm:
    """Welford mean/variance, for scaling a reward term of unknown size."""

    def __init__(self) -> None:
        self.count = 0
        self.mean = 0.0
        self._m2 = 0.0

    def update(self, value: float) -> None:
        self.count += 1
        delta = value - self.mean
        self.mean += delta / self.count
        self._m2 += delta * (value - self.mean)

    @property
    def std(self) -> float:
        return 0.0 if self.count < 2 else float(np.sqrt(self._m2 / self.count))

    def normalise(self, value: float) -> float:
        return float(value) / (self.std + 1e-8)


class WorldModelBonus:
    def __init__(self, jepa, device: str = "cpu", coef: float = 0.05):
        self.jepa = jepa
        self.device = device
        self.coef = coef
        self.norm = RunningNorm()

    def bonus(self, prev_embedding, action_index: int, next_embedding) -> float:
        """How wrong the predictor was about this transition, scaled."""
        initial = torch.from_numpy(np.asarray(prev_embedding, dtype=np.float32)).unsqueeze(0)
        button = torch.from_numpy(to_multihot(action_index)).view(1, 1, -1)
        with torch.no_grad():
            predicted = self.jepa.rollout(initial.to(self.device), button.to(self.device))[:, 0]
        target = torch.from_numpy(np.asarray(next_embedding, dtype=np.float32)).unsqueeze(0)
        error = float(((predicted.cpu() - target) ** 2).mean())
        self.norm.update(error)
        return self.coef * self.norm.normalise(error)

# scripts/collect_part2.py
"""Record frames over the Part 2 maps, for the encoder refresh.

The oracle's action log does not replay -- measured, see
results/part2_ceiling.json -- so the demonstrations it could have provided are
not available. What it does provide is five save states, one per milestone, and
those are where the interesting maps are. So: start from each of them and walk.

Two walk kinds, because uniform random is a poor photographer. "random" is
uniform over the seven actions. "sticky" repeats the previous action with
probability STICKY, which is how you get down a corridor instead of vibrating
in a doorway -- the same trick the noisy variants in scripts/collect.py use.
Handlers run in both, so dialogue is advanced rather than stared at, and the
frames that land in the dataset are the frames a policy will actually see.
"""

from __future__ import annotations

import argparse
import random
from dataclasses import dataclass
from pathlib import Path

from poke.actions import ACTIONS, n_actions, to_multihot
from poke.env import PokeEnv
from poke.handlers import HandlerState, choose
from poke.objectives import CHAIN
from poke.ram import coords, cur_map, party_count, party_species
from poke.writer import EpisodeWriter

#: One per milestone the oracle reached, plus the two Part 1 states, so the
#: refreshed encoder keeps the maps the old one already knew.
MILESTONE_STATES = (
    "states/bedroom.state",
    "states/oracle/route1.state",
    "states/oracle/parcel.state",
    "states/oracle/pokedex.state",
    "states/oracle/forest_gate.state",
    "states/oracle/forest.state",
)

#: Probability a sticky walk repeats its last button.
STICKY = 0.7


@dataclass(frozen=True)
class Job:
    state: str
    seed: int
    kind: str


def episode_plan(states, per_state: int, seed: int) -> list[Job]:
    """Which episodes to record, in order. Pure: the tests run without a ROM."""
    jobs = []
    for index, state in enumerate(states):
        for episode in range(per_state):
            jobs.append(Job(
                state=state,
                seed=seed + index * per_state + episode,
                kind="random" if episode % 2 == 0 else "sticky",
            ))
    return jobs


def walk(rng: random.Random, kind: str, previous: int) -> int:
    if kind == "sticky" and previous >= 0 and rng.random() < STICKY:
        return previous
    return rng.randrange(n_actions())


def record_episode(env, writer, actions: int, seed: int, kind: str, name: str) -> dict:
    """One episode: walk, let the handlers work, write every frame."""
    frame = env.reset()
    rng = random.Random(seed)
    handlers = HandlerState()
    reached = {objective.key for objective in CHAIN if objective.reached(env)}
    previous, maps = -1, set()

    for _ in range(actions):
        claimed = choose(env, handlers)
        action = claimed[0] if claimed else walk(rng, kind, previous)
        before = cur_map(env)
        hit = any(objective.reached(env) and objective.key not in reached
                  for objective in CHAIN)
        writer.add_step(frame[..., 0], to_multihot(action), party_count(env),
                        hit, (before, *coords(env)))
        frame = env.step(action)
        handlers.note(action, cur_map(env) != before)
        previous = action
        maps.add(cur_map(env))
        for objective in CHAIN:
            if objective.reached(env):
                reached.add(objective.key)

    writer.add_step(frame[..., 0], to_multihot(ACTIONS.index("noop")),
                    party_count(env), False, (cur_map(env), *coords(env)))
    species = party_species(env)
    writer.end_episode(kind, name, True, -1 if species is None else species, -1)
    return {"maps": sorted(m for m in maps if m is not None)}


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--rom", default="pokeyellow.gbc")
    parser.add_argument("--out", default="episodes/part2.h5")
    parser.add_argument("--per-state", type=int, default=40)
    parser.add_argument("--actions", type=int, default=250)
    parser.add_argument("--seed", type=int, default=0)
    args = parser.parse_args()

    jobs = episode_plan(MILESTONE_STATES, args.per_state, args.seed)
    covered = set()
    with EpisodeWriter(args.out, args.rom, MILESTONE_STATES[0], act_frames=60,
                       seed=args.seed, game="yellow", task="yellow_part2") as writer:
        for index, job in enumerate(jobs, start=1):
            env = PokeEnv(args.rom, job.state)
            # No settle(): it shifts the frame phase, and these episodes are
            # the record of what a given button sequence produces.
            report = record_episode(env, writer, args.actions, job.seed, job.kind,
                                    f"{Path(job.state).stem}-{job.seed}")
            env.close()
            covered.update(report["maps"])
            print(f"{index}/{len(jobs)} {job.kind:7s} {job.state} maps={report['maps']}",
                  flush=True)
    print("maps covered:", sorted(covered))


if __name__ == "__main__":
    main()

Four worker processes each hold a PyBoy and a TrainEnv; the driver holds the
encoder, the policy, the archive and PPO. Frames cross the pipe (23 KB each,
about 55 MB/s at the measured rate) because the encoder lives on MPS in the
driver and four processes sharing one GPU queue is worse than the copy.

What the driver owns and the workers do not: the archive. A worker reports the
cell it is standing in; when that cell is new the driver asks for a snapshot.
Blobs are 178 KB, so asking only on a new cell is the difference between a few
megabytes an hour and a few gigabytes.

Stopping is wall-clock, not steps. The step rate is an estimate; the overnight
window is not. The kill rule from the design is separate and earlier: if no
episode has completed `get_parcel` by --kill-after-hours, the reward or the

    out_dir: str = "checkpoints/rl"

    rollout_steps: int = 128
    episode_len: int = 512
    bonus_coef: float = 0.05
    max_hours: float = 9.0
    kill_after_hours: float = 3.0
    kill_unless: str = "get_parcel"
    checkpoint_every: int = 10
    seed: int = 0
    ppo: PPOConfig = field(default_factory=PPOConfig)


def should_stop(elapsed_hours: float, completed: set, config: TrainConfig) -> str | None:
    """Why training should end, or None. Pure, so the rule is testable."""
    if elapsed_hours >= config.max_hours:
        return "time"
    if (config.kill_after_hours is not None
            and elapsed_hours >= config.kill_after_hours
            and config.kill_unless not in completed):
        return "kill-rule"
    return None


# -- the worker process ----------------------------------------------------

def worker_loop(pipe, rom, state, episode_len):
    from poke.control import has_control
    env = TrainEnv(rom=rom, state_path=state, episode_len=episode_len)
    step = env.reset()
    while True:
        message, payload = pipe.recv()
        if message == "close":
            env.env.close()
            return
        if message == "reset":
            step = env.reset(payload)
        elif message == "step":
            step = env.step(int(payload))
            if step.done:
                step = env.reset(payload if payload is None else None)
        elif message == "snapshot":
            pipe.send(env.snapshot())
            continue
        info = dict(step.info)
        info["can_snapshot"] = has_control(env.env)
        pipe.send({"frame": step.frame, "objective": step.objective,
                   "reward": step.reward, "done": step.done, "info": info})


class WorkerHandle:
    """One worker process and its pipe, restartable."""

    def __init__(self, rom, state, episode_len):
        self.spec = (rom, state, episode_len)
        self.process = None
        self.pipe = None
        self.restart()

    def restart(self):
        if self.process is not None and self.process.is_alive():
            self.process.terminate()
        parent, child = Pipe()
        self.pipe = parent
        self.process = Process(target=worker_loop, args=(child, *self.spec), daemon=True)
        self.process.start()

    def send(self, message):
        self.pipe.send(message)

    def recv(self):
        return self.pipe.recv()

    def close(self):
        try:
            self.send(("close", None))
        except (BrokenPipeError, OSError):
            pass


# -- the driver ------------------------------------------------------------

class Trainer:
    def __init__(self, handles, policy, encoder, archive, bonus, config, device="cpu"):
        self.handles = list(handles)
        self.policy = policy
        self.encoder = encoder
        self.archive = archive
        self.bonus = bonus
        self.config = config
        self.device = device
        self.stacks = [EmbeddingStack(encoder.num_frames, encoder.dim) for _ in handles]
        self.prev_action = [0] * len(handles)
        self.objectives = [[0.0] * N_OBJECTIVES for _ in handles]
        self.hidden = policy.initial_hidden(len(handles), device)
        self.completed: set[str] = set()
        self.steps = 0
        self.started = False

    def new_buffer(self) -> RolloutBuffer:
        return RolloutBuffer(self.config.rollout_steps, len(self.handles),
                             self.policy.obs_dim, device=self.device)

    def _observe(self, replies, first: bool):
        frames = np.stack([reply["frame"] for reply in replies])
        embeddings = self.encoder.embed(frames)
        rows = []
        for index, reply in enumerate(replies):
            if first:
                self.stacks[index].reset(embeddings[index])
            else:
                self.stacks[index].push(embeddings[index])
            self.objectives[index] = reply["objective"]
            rows.append(observation(self.stacks[index].vector(), reply["objective"],
                                    self.prev_action[index], self.policy.n_actions))
        return torch.from_numpy(np.stack(rows)).float().to(self.device), embeddings

    def _archive_cells(self, replies, dead):
        for index, reply in enumerate(replies):
            if index in dead or not reply["info"].get("can_snapshot"):
                continue
            info = reply["info"]
            objective = int(np.argmax(reply["objective"]))
            key = (objective, info["map"], (info["y"] or 0) // CELL, (info["x"] or 0) // CELL)
            if key in self.archive.cells:
                self.archive.note_visit(key)
                continue
            self.handles[index].send(("snapshot", None))
            blob = self.handles[index].recv()
            self.archive.cells[key] = type(self.archive).__mro__[0] and __import__(
                "poke.rl.archive", fromlist=["Cell"]).Cell(key=key, blob=blob,
                                                           found_at=len(self.archive) + 1)

    def _reset_all(self):
        replies, dead = [], set()
        for index, handle in enumerate(self.handles):
            handle.send(("reset", self.archive.sample()))
            try:
                replies.append(handle.recv())
            except (EOFError, OSError):
                handle.restart()
                dead.add(index)
                replies.append(self._blank())
        return replies, dead

    def _blank(self):
        return {"frame": np.zeros((144, 160), dtype=np.uint8),
                "objective": [0.0] * N_OBJECTIVES, "reward": 0.0, "done": False,
                "info": {"map": None, "y": 0, "x": 0, "completed": [],
                         "controllers": {}, "taken": 0, "can_snapshot": False}}

    def collect(self, buffer: RolloutBuffer) -> dict:
        """One rollout. Returns which env columns are usable for the update."""
        dropped: set[int] = set()
        if not self.started:
            replies, dead = self._reset_all()
            dropped |= dead
            obs, previous_embeddings = self._observe(replies, first=True)
            self.started = True
        else:
            replies, dead = self._reset_all()
            dropped |= dead
            obs, previous_embeddings = self._observe(replies, first=True)

        for t in range(buffer.steps):
            with torch.no_grad():
                out = self.policy.act(obs, self.hidden)
            self.hidden = out["hidden"]
            actions = out["action"].tolist()

            replies = []
            for index, handle in enumerate(self.handles):
                handle.send(("step", actions[index]))
            for index, handle in enumerate(self.handles):
                try:
                    replies.append(handle.recv())
                except (EOFError, OSError):
                    handle.restart()
                    dropped.add(index)
                    replies.append(self._blank())

            next_obs, embeddings = self._observe(replies, first=False)
            rewards = []
            for index, reply in enumerate(replies):
                reward = float(reply["reward"])
                if self.bonus is not None and index not in dropped:
                    # Policy transitions only: a handler turn is a text box,
                    # and a text box is a noisy TV.
                    reward += self.bonus.bonus(previous_embeddings[index],
                                               actions[index], embeddings[index])
                rewards.append(reward)
                self.completed.update(reply["info"]["completed"])
                self.prev_action[index] = actions[index]

            buffer.add(t, obs=obs, action=out["action"],
                       logprob=out["logprob"], value=out["value"],
                       reward=torch.tensor(rewards, device=self.device),
                       done=torch.tensor([float(r["done"]) for r in replies],
                                         device=self.device))
            self._archive_cells(replies, dropped)
            obs, previous_embeddings = next_obs, embeddings
            self.steps += len(self.handles)

        self.last_obs = obs
        usable = [i for i in range(len(self.handles)) if i not in dropped]
        return {"dropped_workers": sorted(dropped), "usable_envs": usable}


def save_checkpoint(path, policy, optimizer, updates, steps, completed):
    Path(path).parent.mkdir(parents=True, exist_ok=True)
    torch.save({"policy": policy.state_dict(), "optimizer": optimizer.state_dict(),
                "updates": updates, "steps": steps, "completed": sorted(completed)}, path)


def load_checkpoint(path, policy, optimizer) -> dict:
    blob = torch.load(path, map_location="cpu", weights_only=False)
    policy.load_state_dict(blob["policy"])
    optimizer.load_state_dict(blob["optimizer"])
    return {"updates": blob["updates"], "steps": blob["steps"],
            "completed": set(blob["completed"])}


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    defaults = TrainConfig()
    parser.add_argument("--rom", default=defaults.rom)
    parser.add_argument("--state", default=defaults.state)
    parser.add_argument("--checkpoint", default=defaults.checkpoint,
                        help="the frozen encoder")
    parser.add_argument("--out-dir", default=defaults.out_dir)
    parser.add_argument("--workers", type=int, default=defaults.workers)
    parser.add_argument("--rollout-steps", type=int, default=defaults.rollout_steps)
    parser.add_argument("--episode-len", type=int, default=defaults.episode_len)
    parser.add_argument("--bonus-coef", type=float, default=defaults.bonus_coef)
    parser.add_argument("--max-hours", type=float, default=defaults.max_hours)
    parser.add_argument("--kill-after-hours", type=float, default=defaults.kill_after_hours)
    parser.add_argument("--resume", default=None)
    parser.add_argument("--seed", type=int, default=defaults.seed)
    parser.add_argument("--device", default=default_device())
    parser.add_argument("--log", default="results/part2_rl_train.json")
    args = parser.parse_args()

    torch.manual_seed(args.seed)
    config = TrainConfig(rom=args.rom, state=args.state, checkpoint=args.checkpoint,
                         out_dir=args.out_dir, workers=args.workers,
                         rollout_steps=args.rollout_steps, episode_len=args.episode_len,
                         bonus_coef=args.bonus_coef, max_hours=args.max_hours,
                         kill_after_hours=args.kill_after_hours, seed=args.seed)

    encoder = FrozenEncoder(config.checkpoint, device=args.device)
    policy = ActorCritic(feature_dim=encoder.dim, num_frames=encoder.num_frames).to(args.device)
    optimizer = torch.optim.Adam(policy.parameters(), lr=config.ppo.lr)
    bonus = WorldModelBonus(encoder.model, device=args.device, coef=config.bonus_coef)
    archive = Archive()
    handles = [WorkerHandle(config.rom, config.state, config.episode_len)
               for _ in range(config.workers)]

    state = {"updates": 0, "steps": 0, "completed": set()}
    if args.resume:
        state = load_checkpoint(args.resume, policy, optimizer)

    driver = Trainer(handles, policy, encoder, archive, bonus, config, device=args.device)
    driver.completed = set(state["completed"])
    started = time.time()
    history = []
    reason = None

    try:
        while reason is None:
            buffer = driver.new_buffer()
            report = driver.collect(buffer)
            with torch.no_grad():
                _, last_value, _ = policy(driver.last_obs, driver.hidden)
            buffer.compute_returns(last_value, torch.zeros_like(last_value), config.ppo)
            stats = ppo_update(policy, optimizer, buffer, config.ppo,
                               policy.initial_hidden(len(handles), args.device))
            state["updates"] += 1
            elapsed = (time.time() - started) / 3600.0
            row = {"update": state["updates"], "steps": driver.steps,
                   "hours": round(elapsed, 3), "archive": archive.stats(),
                   "completed": sorted(driver.completed),
                   "dropped_workers": report["dropped_workers"], **stats}
            history.append(row)
            print(json.dumps(row), flush=True)
            if state["updates"] % config.checkpoint_every == 0:
                save_checkpoint(Path(config.out_dir) / "last.pt", policy, optimizer,
                                state["updates"], driver.steps, driver.completed)
            reason = should_stop(elapsed, driver.completed, config)
    finally:
        save_checkpoint(Path(config.out_dir) / "last.pt", policy, optimizer,
                        state["updates"], driver.steps, driver.completed)
        for handle in handles:
            handle.close()

    Path(args.log).parent.mkdir(parents=True, exist_ok=True)
    Path(args.log).write_text(json.dumps({
        "stopped": reason,
        "updates": state["updates"],
        "steps": driver.steps,
        "hours": round((time.time() - started) / 3600.0, 3),
        "completed": sorted(driver.completed),
        "bonus": MEASURED["chosen"],
        "archive": archive.stats(),
        "history": history[-200:],
    }, indent=1))
    print("stopped:", reason, "completed:", sorted(driver.completed))


if __name__ == "__main__":
    main()

"""Score the trained policy under the play-time contract.

Ten sampling seeds and one greedy run, each a single continuous episode from
states/oracle/route1.state with a 1,461-action budget -- 3x the oracle's 487,
fixed in results/part2_ceiling.json. The policy sees `PlayTimeEnv`: pixels, the
frozen encoder, the objective one-hot. Any reach for the map id or the
coordinates raises rather than returning a number.

Every run writes a GIF. The design is explicit that a human watches them,
because a reward hack shows up there before it shows up in a table.
"""

from __future__ import annotations

import argparse
import json
import random
import statistics
from pathlib import Path

import numpy as np
import torch
from PIL import Image

from poke.contract import Run
from poke.env import PokeEnv
from poke.goals import default_device
from poke.objectives import CHAIN
from poke.rl.features import EmbeddingStack, FrozenEncoder
from poke.rl.policy import ActorCritic, observation
from scripts.play2 import play

#: 3x the oracle's 487 actions.
BUDGET = 1461
#: The design's bar: map 51 on at least this many of ten seeds.
DONE_SEEDS = 5


class NetPolicy:
    """The trained net, in the slot scripts/play2.py gives a policy.

    It touches exactly one thing on the guarded env: `screen()`. The frame
    history and the GRU state live here, because the contract gives the policy
    no memory of its own.
    """

    def __init__(self, policy, encoder, device="cpu", greedy=False, seed=0):
        self.policy = policy
        self.encoder = encoder
        self.device = device
        self.greedy = greedy
        self.rng = random.Random(seed)
        torch.manual_seed(seed)
        self.stack = EmbeddingStack(encoder.num_frames, encoder.dim)
        self.reset()

    def reset(self) -> None:
        self.hidden = self.policy.initial_hidden(1, self.device)
        self.prev_action = 0
        self.stack.buffer = None
        self.frames: list[np.ndarray] = []

    def __call__(self, env, objective_one_hot) -> int:
        screen = env.screen()
        self.frames.append(screen)
        embedding = self.encoder.embed(screen[:, :, 0][None, ...])[0]
        if self.stack.buffer is None:
            self.stack.reset(embedding)
        else:
            self.stack.push(embedding)
        obs = observation(self.stack.vector(), objective_one_hot,
                          self.prev_action, self.policy.n_actions)
        tensor = torch.from_numpy(obs).float().unsqueeze(0).to(self.device)
        with torch.no_grad():
            out = self.policy.act(tensor, self.hidden, greedy=self.greedy)
        self.hidden = out["hidden"]
        self.prev_action = int(out["action"].item())
        return self.prev_action


def write_gif(frames, path, every=6, scale=1) -> None:
    """Subsampled, so a 1,461-action run is a few hundred kilobytes."""
    if not frames:
        return
    images = [Image.fromarray(frame) for frame in frames[::every]]
    if scale != 1:
        images = [img.resize((img.width * scale, img.height * scale), Image.NEAREST)
                  for img in images]
    Path(path).parent.mkdir(parents=True, exist_ok=True)
    images[0].save(path, save_all=True, append_images=images[1:],
                   duration=60, loop=0, optimize=True)


def summarise(runs) -> dict:
    keys = [objective.key for objective in CHAIN]
    reached = {key: sum(1 for run in runs if run["objectives"].get(key) is not None)
               for key in keys}
    shares = [run["learned_share"] for run in runs]
    forest_runs = [run for run in runs if run["objectives"].get("enter_forest") is not None]
    return {
        "seeds": len(runs),
        "reached": reached,
        "passes_done_threshold": reached.get("enter_forest", 0) >= DONE_SEEDS,
        "median_learned_share": statistics.median(shares) if shares else 0.0,
        "actions_to_forest": sorted(run["objectives"]["enter_forest"] for run in forest_runs),
        "runs": runs,
    }

    parser.add_argument("--rom", default="pokeyellow.gbc")
    parser.add_argument("--state", default="states/oracle/route1.state")
    parser.add_argument("--encoder", default="checkpoints/part2/best.pt")
    parser.add_argument("--policy", default="checkpoints/rl/last.pt")
    parser.add_argument("--seeds", type=int, default=10)
    parser.add_argument("--budget", type=int, default=BUDGET)
    parser.add_argument("--device", default=default_device())
    parser.add_argument("--gif-dir", default="media")
    parser.add_argument("--out", default="results/part2_rl_eval.json")
    args = parser.parse_args()

    encoder = FrozenEncoder(args.encoder, device=args.device)
    net = ActorCritic(feature_dim=encoder.dim, num_frames=encoder.num_frames).to(args.device)
    blob = torch.load(args.policy, map_location="cpu", weights_only=False)
    net.load_state_dict(blob["policy"])
    net.eval()

    runs = []
    for seed in list(range(args.seeds)) + ["greedy"]:
        greedy = seed == "greedy"
        policy = NetPolicy(net, encoder, device=args.device, greedy=greedy,

        # No settle(): it shifts the frame phase, measured in Stage 1.

        runs.append(result)
        print(json.dumps({k: result[k] for k in
                          ("seed", "objectives", "actions", "learned_share")}), flush=True)

    sampled = [run for run in runs if not run["greedy"]]
    report = summarise(sampled)
    report["greedy"] = next(run for run in runs if run["greedy"])
    report["budget"] = args.budget
    report["ceiling_actions"] = 487
